# Weather App

A Python-based weather application that fetches real-time weather information for any city.

## Features

- Search weather by city name
- Displays temperature
- Displays weather condition
- Displays humidity
- Displays wind speed
- Displays latitude and longitude
- Allows checking multiple cities

## Technologies Used

- Python
- Requests
- Weather API
